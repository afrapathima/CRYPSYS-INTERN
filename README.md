# crypsys ERP – Frontend (React + Vite)

    npm install
    npm run dev

Open http://localhost:5173

Demo: login `admin` / `admin123`, OTP `123456`. Or register a business, then sign in.
Auth is mocked in `src/auth.jsx` (localStorage) – replace each function with your API calls.
To use your real logo: put `logo.png` in `/public` and render `<img src="/logo.png" />` in `src/components/Logo.jsx`.
